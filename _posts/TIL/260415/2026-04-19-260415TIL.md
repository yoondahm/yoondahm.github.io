# 비동기식 입력감지
이때까지 입력은 전부 동기식으로 받았었다. std::cin은 입력이 들어오기 전까지 메인 스레드를 차단하는 특성이 있었고, \_getch()역시 마찬가지였다.
```cpp
if(_kbhit()) {
	char input = _getch();
}
```
이렇게 \_kbhit을 확인 후 \_getch를 하여 비동기 입력처럼 사용할 수 있긴 하지만, 본질적으로 \_getch() 자체는 동기식 입력이다.

`GetAsyncState()`는 `WinUser.h`에 들어있는 함수로, 어떤 키의 현재 상태를 알려준다. `WinUser.h`는 `Windows.h`에서 include하고 있기 때문에 `Windows.h`를 사용중이라면 따로 include해줄 필요는 없다.

`GetAsyncState()`에서 상태를 알고싶은 키는 `WinUser.h`에 있는 `VK_` 매크로를 통해 넣어주면 된다. 예를 들어 화살표 Up키의 상태를 알고 싶은 경우 `GetAsyncState(VK_UP)`을 하면 된다.

나온 결과는 비트 연산을 통해 알 수 있다. `GetAsyncKeyState(vKey) & 0x8000`의 경우 현재 프레임에 눌려 있는 지를 반환한다.
