static이 아닌 전역변수는 항상 변경을 막자. (const)
전역변수 -> 수정o: static 전역변수 / 수정x : const 전역변수

const와 constexpr
const는 변수를 상수화 하는 키워드로, 한 번 할당한 값을 바꿀 수 없도록 해주는 역할이다.
```cpp
const int x = 10;
x = 11; // 에러
```

constexpr도 상수를 만든다는 부분에서 헷갈릴 수 있지만, 아래 예시를 보면 명확한 차이를 느낄 수 있다.
```cpp
int test() { return 0; }

int main() {
	const int x = test(); // 됨
	constexpr int y = test(); // 안됨.
}
```

constexpr은 완전 컴파일타임 상수만 취급.
constexpr - 정적 바인딩
const - 동적 바인딩

C#으로 따지자면

| C++       | C#       |
| --------- | -------- |
| const     | readonly |
| constexpr | const    |

"상수"라는 의미에 더 맞는 쪽은 C#인 것 같다.
항상 느끼지만 C++은 키워드 이름을 참 애매하게 지었다. (+일관성이 없다.)

const는 사실 컴파일타임 상수도 취급하기에 엄밀히 따져서 C#의 readonly랑은 다른데, 밑의 예시를 보면 알 수 있다.
```cpp
int a = 10;
int arr[a]{}; // 에러
```
위 예시의 a는 변수이기 때문에 배열의 크기로 쓸 수 없다.
```cpp
const int a = 10;
int arr[a]{}; // 된다?
```
반면 위 예시는 const가 붙었고, a에 할당되는 값이 constant expression이기 때문에 constexpr과 같은 취급, 즉 컴파일 타임 상수로 처리되며, 리터럴처럼 쓰일 수 있다. 따라서 배열의 크기로 쓸 수 있다.
```cpp
int test() { return 0; }

const int a = test();
int arr[a]{}; // 안된다.
```
하지만 위 예시의 const는 constant expression가 아닌 값을 할당했기 때문에, 런타임 상수로 취급된다.
