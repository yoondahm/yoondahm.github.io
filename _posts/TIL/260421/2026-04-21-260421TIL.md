# std::setw
`iomanip` 헤더에 있는 함수로, 다음 `cout`이 최소 몇 칸을 먹을 지를 정해준다. 예를 들어
```cpp
cout << std::setw(3) << '1';
```
이렇게 사용할 시, '1'은 출력될 때 세 칸을 먹는다. 쉽게 말해 1 앞에 2개 생긴다고 보면 된다. 원래 '1'은 한 칸을 먹지만, 최소 3칸을 먹어야 하기 때문에 2칸을 추가로 먹고 '1'이 출력된다.

하지만 만약 똑같이 세 칸을 먹고 싶은데, 먼저 출력한 뒤 남은 칸을 먹고 싶을 수 있다. 그럴 땐 `std::left`를 사용하면 된다.

# std::left
먼저 출력한 뒤 남은 칸을 먹게 해주는 아이다. 예를 들어
```cpp
cout << std::setw(5) << 1 << ' ' << std::setw(3) << 2;
```
이렇게 해준다면 원래 출력 결과는

&nbsp;&nbsp;&nbsp;&nbsp;1&nbsp;&nbsp;&nbsp;2

겠지만,
```cpp
cout << std::left;
cout << std::setw(5) << 1 << ' ' << std::setw(3) << 2;
```
이렇게 해준다면

1&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;2&nbsp;&nbsp;

가 된다.

# std::to_string
인수를 `string`으로 변환해준다.
말 그대로
```cpp
std::to_string(120);
```
을 넣으면 "120"이 반환된다.
`to_string`은 각 자료형에 대해
```cpp
_EXPORT_STD _NODISCARD inline string to_string(int _Val) {
    return _Integral_to_string<char>(_Val);
}

_EXPORT_STD _NODISCARD inline string to_string(unsigned int _Val) {
    return _Integral_to_string<char>(_Val);
}

_EXPORT_STD _NODISCARD inline string to_string(long _Val) {
    return _Integral_to_string<char>(_Val);
}

_EXPORT_STD _NODISCARD inline string to_string(unsigned long _Val) {
    return _Integral_to_string<char>(_Val);
}

_EXPORT_STD _NODISCARD inline string to_string(long long _Val) {
    return _Integral_to_string<char>(_Val);
}

_EXPORT_STD _NODISCARD inline string to_string(unsigned long long _Val) {
    return _Integral_to_string<char>(_Val);
}
// ...
```
이런 식으로 각각 만들어져있다.
C#에선 `ToString()`메서드가 모든 타입의 조상인 `object`에서 가지고 있기 때문에 훨씬 유연성, 호환성 등이 좋은 것 같다.

# 마우스 입력
기본적으로 콘솔앱에선 클릭을 할 시 해당 글자가 선택되었었다. 글자 선택이 되면 제대로 된 마우스 입력을 받을 수 없기 때문에 막아줄 필요가 있다.
```cpp
HANDLE handle = GetStdHandle(STD_INPUT_HANDLE);
DWORD mode;
GetConsoleMode(handle, &mode);
mode &= ~ENABLE_QUICK_EDIT_MODE; // 퀵 에디트 모드 끄기
mode &= ~ENABLE_INSERT_MODE; // 인서트 모드 끄기
mode |= ENABLE_MOUSE_INPUT; // 마우스 입력은 받되, 퀵 에디트 모드와 인서트 모드는 끄기
mode |= ENABLE_EXTENDED_FLAGS; // 확실히 적용하기 위해

SetConsoleMode(handle, mode);
```
설명은 주석에 적어 두었다.
이것 역시 콘솔의 설정을 건드리는 것이기 때문에 `HANDLE`이 필요하다.
