# string.resize(size_t \_New_size, char \_Ch)
문자열의 사이즈가 \_New_size가 되도록 늘리고, 남은 공간은 전부 \_Ch로 채운다. 수업 중엔
```cpp
void AsciiInit(AsciiObjs& objs)
{
	objs.plane =
	{
	   "         _       ",
	   "      -= \\`\\     ",
	   "   |\\ ____\\_\\__  ",
	   "-= \\c`\"\"\"\"\"\"\" \"`)",
	   "    `~~~~~/ /~~` ",
	   "    -= = / /     ",
	   "        '-'      ",
	};
	objs.cloud =
	{
	 "      _  _       ",
	 "    ( `   )_     ",
	 "   (    )    `)  ",
	 " (_   (_ .  _) _)",
	};

	for (string& line : objs.plane)
		line.resize(WIDTH, ' ');
	for (string& line : objs.cloud)
		line.resize(WIDTH, ' ');
}
```
여기서 사용했는데, 아스키아트의 사이즈를 화면 사이즈와 맞춰 std::rotate했을 때 화면을 가르지르도록 하였다.

# FlashAnim
```cpp
void FlashAnim(COORD res, int count, int delayMs)
{
	for (int i = 0; i < count; ++i)
	{
		SetColor(Color::BLACK, Color::WHITE);
		system("cls");
		Sleep(delayMs);

		SetColor();
		system("cls");
		Sleep(delayMs);
	}
}
```
화면을 깜빡깜빡 거리도록 만드는 함수이다.
특이하게도 system("cls")를 사용하였는데, 이는 cls가 화면 전체를 문자로 채우는 원리이기 때문이다.
따라서 SetColor()이후 system("cls")를 사용하면 원하는 색으로 화면을 채울 수 있다.
# CrossAnim
```cpp
void CrossAnim(COORD res, int delayMs)
{
	SetColor(Color::BLACK, Color::WHITE);
	for (int x = 0; x < res.X / 2; ++x) {
		for (int y = 0; y < res.Y; y += 2) {
			GotoXY(x * 2, y);
			cout << "  ";
		}
		for (int y = 1; y < res.Y; y += 2) {
			GotoXY(res.X - 2 - x * 2, y);
			cout << "  ";
		}
		Sleep(delayMs);
	}
	SetColor();
}
```
이건 화면 양쪽에서 선을 교차시켜 화면을 채우도록 하는 함수이다.
특별히 설명할 부분이라면 SetColor로 배경색을 흰색으로 만들고 공백을 출력하는 방식으로 하얗게 채웠다는 점 정도가 있다.
# std::setfill(char \_Ch)
원래 std::setw는 남는 공간을 공백 문자로 채우지만, std::setfill을 사용하면 다른 문자로 채우게 할 수 있다. 이를 활용해
```cpp
void DrawLine(char ch, int width)
{
	cout << std::setfill(ch) << std::setw(width);
}
```
이런 함수를 만들었다.
