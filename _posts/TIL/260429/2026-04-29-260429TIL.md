# 콘솔창의 해상도 가져오기
```cpp
COORD GetConsoleResolution()
{
	HANDLE handle = GetStdHandle(STD_OUTPUT_HANDLE);
	CONSOLE_SCREEN_BUFFER_INFO info;
	GetConsoleScreenBufferInfo(handle, &info);
	short width = info.srWindow.Right - info.srWindow.Left + 1;
	short height = info.srWindow.Bottom - info.srWindow.Top + 1;
	return { width, height };
}
```

# std::rotate
circular shift, bitwise roll? 정도의 명칭으로 불리는 비트 연산을 STL에 쓸 수 있게 해주는 함수이다.
엄밀히 따지자면 STL에만 쓸 수 있는 건 아니고, iterator만 있으면 어디든 쓸 수 있다.
벡터에서 쓸 때의 예시를 보자.
다음과 같은 벡터가 있다.
```cpp
std::vector<int> v = { 1, 2, 3, 4, 5 };
```
여기서 std::rotate를 다음과 같이 쓰면
```cpp
std::rotate(v.begin(), v.begin() + 1, v.end());
```
v의 값은 2 3 4 5 1 이 된다.
즉 두 번째 인수의 인덱스가 가장 앞에 오도록 당기고, 나머진 circular shift처럼 처리하는 것이다.
그렇다면 반대로 돌리고 싶다면 어떻게 할까?
그럴 땐 반대로 된 iterator를 쓰면 된다.
```cpp
std::rotate(v.rbegin(), v.rbegin() + 1, v.rend());
```
# iterator
아까부터 iterator iterator하는데, 그래서 iterator가 뭘까?
iterator는 마치 컨테이너를 순회하기 위한 포인터 비스무리 한 것? 이다.
it이라는 iterator가 있을 때, `*it`을 하면 역참조가 되고, `++it`을 하면 다음 요소로 이동하는 식이다. 즉, 포인터처럼 생겼지만 훨씬 추상화된 객체로 보면 된다.
이 친구 덕분에 다양한 컨테이너를 일관되게 순회할 수 있다.
`vector`, `list`, `string` 등등 전부 iterator를 반환하는 함수를 구현해 두었기 때문에 그걸 가져다 쓰면 되는 거다.

이걸 보면 C#의 `IEnumerator`와 굉장히 유사한 역할인 것을 알 수 있다. 또 이걸 응용하여`foreach`처럼 사용할 수 있는데
```cpp
std::vector<int> v = { 1, 2, 3, 4, 5 };

for (auto it = v.begin(); it != v.end(); ++it) {
    std::cout << *it << '\n';
}
```
이런 느낌으로 쓸 수 있고, 이건 사실
```cpp
for (int x : v) {
    std::cout << x << '\n';
}
```
이렇게 쓸 수 있다. (저것도 내부적으로 iterator를 사용한다.)
