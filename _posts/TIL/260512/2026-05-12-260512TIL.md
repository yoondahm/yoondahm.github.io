### 1. DrawLine
```cpp
void DrawLine(char ch, int width)
{
	cout << std::setfill(ch) << std::setw(width)
		<< "" << std::setfill(' ');
}
```
`std::setfill`로 `std::setw`를 통해 채울 문자를 정한다.
그 후, 공백을 출력하면 `std::setw`를 통한 문자만이 출력된다.
여기서 포인트는 `std::setw`는 1회용이지만, `std::setfill`은 한 번 설정한 값으로 유지되기 때문에, `std::setfill`을 쓴 뒤 다시 원래 문자로 되돌려 두어야 한다.
그렇지 않으면 의도치 않은 동작이 발생할 수 있다.

### 2. 이동 로직
```cpp
void MovePlayer(GameState& state)
{
	Player& p = state.player;
	if (state.curTime - p.lastMoveTime < p.moveInterval)
		return;
	Position dir = GetMoveDir();
	if (dir == Position{ 0,0 })
		return;
	Position next = {
		std::clamp(p.pos.x + dir.x, 0, MAP_W - 1),
		std::clamp(p.pos.y + dir.y, 0, MAP_H - 1)
	};
	if (!CanMove(state.map, next.x, next.y))
		return;

	p.pos = next;
	p.lastMoveTime = state.curTime;
}
```
플레이어의 이동속도는 `lastMoveTime`으로부터 지난 시간이 `moveInterval`보다 클 때만 움직이도록 하여 구현하였다. 만약 이동속도를 빨라지게 하고 싶다면 단순히 `moveInterval`을 줄이는 것으로 구현할 수 있다.

### 3. 연산자 오버로딩
```cpp
int x = 3, y = 2;
if (x == y) {
	//
}
```
이건 된다.
```cpp
Position p1 = { 0, 0 };
Position p2 = { 1, 0 };
if (p1 == p2) {
	//
}
```
이건 기본적으론 안된다.
왜냐하면 `int`는 기본 제공 타입이라 `==`연산자가 이미 만들어져 있는데, `Position`은 내가 직접 만든 타입이기 때문이다.
이를 해결하기 위해선 `==`연산자를 직접 만들어주면 된다.
```cpp
bool operator ==(const Position& other) const {
	return x == other.x && y == other.y;
}
```
문법은 기본적으로 함수와 거의 유사하다. 원래 함수에서 이름을 적는 부분에 `operator 연산자종류`를 적으면 된다. 예를 들어 `+`연산자를 오버로딩 하고 싶다면 `operator +`로 하면 된다.

### 4. vector의 두 가지 push_back
벡터에 요소를 추가하려면 `push_back`을 쓰면 된다.
```cpp
std::vector<int> v;
int x = 0;
v.push_back(x);
```
위 코드에선 변수`x`를 선언하여 그 변수를 `push_back`해 주었다.
그러나 이렇게도 된다.
```cpp
v.push_back(0);
```
이 둘은 언뜻 같아 보일 수 있지만, 서로 다른 함수를 호출한다.
```cpp
    _CONSTEXPR20 void push_back(const _Ty& _Val) {
        _Emplace_one_at_back(_Val);
    }

    _CONSTEXPR20 void push_back(_Ty&& _Val) {
        _Emplace_one_at_back(_STD move(_Val));
    }
```
처음의 경우가 위쪽 오버로딩이고, 두 번째 경우가 아래쪽 오버로딩이다.
이는 값의 종류가 `lvalue`와 `rvalue`로 나뉘어 있기 때문이고, 아래쪽 오버로딩은 오른쪽 값 참조라고 불리는 기법이라 한다. 소유권 이전 등의 여러 개념이 묶여있다고 한다.
