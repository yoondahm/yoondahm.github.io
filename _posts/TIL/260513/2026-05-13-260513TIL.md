### 1. 컨테이너의 분류
STL의 컨테이너는 크게 3개로 나눌 수 있는데, 각각
1. 시퀀스 컨테이너 - ex) vector, list
2. 연관 컨테이너 - ex) map, set
3. 컨테이너 어댑터 - ex) stack, queue // iterator 없음
로 나눌 수 있다.

### 2. iterator 타입
컨테이너 중 시퀀스 컨테이너, 연관 컨테이너는 iterator를 `innerClass` (혹은 `nestedClass`) 로 가지고 있다. 따라서 `vector<int>`의 iterator가 필요하다면 `(std::)vector<int>::iterator`를 타입으로서 쓸 수 있다.

### 3. 화살표 연산자 ->
역참조를 할 때 사용한다. 즉,
`(*ptr).value` 는 `ptr->value`로 간결하게 표현 가능.

### 4. 후치연산보다 전치연산
전치는 단순히 객체의 값을 바꿔준 뒤 반환한다면, 후치연산은 객체의 이전 상태를 스냅샷으로 만든 뒤, 원래 객체의 값을 변경, 이후 스냅샷을 반환하는 방식이다.
`int`처럼 단순한 객체에선 거의 무의미한 성능 차이가 발생하지만, `iterator`같이 복잡한 객체는 복사생성자의 호출 비용 등이 추가적으로 발생하게 되므로 가능한 한 전치 연산을 사용하는 것이 바람직하다.

### 5. 벡터의 요소 제거
`std::vector`의 특정 요소를 제거하고 싶다면 `vector.erase`함수를 사용하면 된다. `vector.erase`는 매개변수로 `iterator`를 받는데, (정확히는 `const_iterator`) 이는 벡터의 요소 전용 포인터와 비슷한 역할이라 보면 된다. (사실 다름)
```cpp
std::vector<Bomb>::iterator iter = bombs.begin();

for (; iter != bombs.end();)
{
	if (!iter->active)
		iter = bombs.erase(iter);
	else
		++iter;
}
```
위 코드는 `Bomb`으로 이루어진 벡터의 요소 중 `!active`인 것만 제거하는 코드인데, `iter = bombs.erase(iter)` 부분이 이상해 보일 수 있다. 이는 `vector.erase`가 새로운 `iterator`를 반환하기 때문인데, 벡터를 `iterator`를 통해 순회하던 중 벡터를 수정한다면 원래의 `iterator`는 유효하지 못한 순회를 하게되기 때문이다. 따라서 `erase`가 반환하는 새로운 유효한 `iterator`를 받아서 그 시점에서 순회를 이어가야 한다.


벡터를 순회 중 erase를 하면 안되는 이유 : C#의 `InvalidOperationException`과 같은 이유.
