받은 모든 입력은 InputInfo구조체의 형태로 버퍼에 담김.
```cs
public struct InputInfo {
	public long Timestamp;
	public Direction Direction;
	public InputButton Button;
}
```
InputInfo는 몇 틱에 눌렸는지, 어떤 방향을 눌렀는지, 어떤 버튼을 눌렀는지의 정보를 담고 있음.
입력은 홀드를 고려하지 않으며, 누른 순간에만 이벤트가 발생함.
